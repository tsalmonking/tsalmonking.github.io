BENCHMARK · LEAD

RAID

A dataset of 72k transferable adversarial examples for evaluating detectors of AI-generated images. Built with an ensemble attack so the examples transfer to detectors that were never part of the attack, which lets you measure robustness without building an attack pipeline first.

github paper

LIBRARY · CONTRIBUTOR

SecML-Torch

A PyTorch library for evaluating the robustness of deep learning models: attacks, defences, and reproducible evaluation loops, kept deliberately close to standard PyTorch so it drops into existing training code.

github

TOOLING · CONTRIBUTOR

android-detectors

End-to-end implementations of machine-learning-based Android malware detectors, used as a common baseline for studying how these models behave under drift and adversarial pressure.
